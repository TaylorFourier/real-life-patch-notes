# real-life-patch-notes

A deterministic program that writes one software patch note for a bug in ordinary human chewing. It prints length counts and the file hash, and it writes UTF-8 text to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline.

## Run it

```sh
mkdir -p out
MAKEFUN_BOT_DIR="$PWD" MAKEFUN_OUTPUT_DIR=./out TZ=UTC PYTHONHASHSEED=0 LANG=C.UTF-8 node main.ts
```
